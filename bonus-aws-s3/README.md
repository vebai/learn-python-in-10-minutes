# Optional Bonus — Automate AWS with Python

Optional: install Boto3, verify `aws sts get-caller-identity`, and make a private lab bucket you control. Copy `employees.json` created by Chapter 7 into this folder. Edit `BUCKET` in the book code to your real bucket name before running. Run `upload_to_s3.py`, verify in AWS, then `cleanup_s3.py` and independently confirm removal. AWS charges may apply; never commit credentials.
