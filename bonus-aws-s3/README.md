# Optional Bonus — Automate AWS with Python

Install Boto3 and check your AWS identity using `aws sts get-caller-identity`. Use your own private lab bucket. Copy `employees.json` from Chapter 7 into this folder and set `BUCKET` to your bucket name. Run `upload_to_s3.py`, verify the upload, then run `cleanup_s3.py` and confirm the objects were removed. AWS charges may apply; never commit credentials.

- `upload_to_s3.py`
