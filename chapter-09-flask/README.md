# Chapter 9 — Build Your First Web API with Flask

Install Flask in your virtual environment. Run `init_db.py`, then `app.py`. Visit `http://127.0.0.1:5000/`, `/employees` and `/employees/1`. The `app_first_route.py` and `app_employees_only.py` files demonstrate earlier stages. Use `update_employee.py` to test live database reads. The Flask server is for local development.
