# Chapter 9 — Build Your First Web API with Flask

Install Flask into your virtual environment. Run `init_db.py`, then `app.py` and visit `/`, `/employees` and `/employees/1` at `http://127.0.0.1:5000`. The `app_first_route.py` and `app_employees_only.py` files preserve earlier stages from the book. Run `update_employee.py` to test live database reads. This is a development server only.

## Files

- `app.py`
- `app_employees_only.py`
- `app_first_route.py`
- `init_db.py`
- `update_employee.py`

The files contain code copied from the book. For individual shorter examples see [`additional-excerpts.md`](additional-excerpts.md) when present.
